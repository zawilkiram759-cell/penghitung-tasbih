# Penghitung Tasbih

Aplikasi web sederhana untuk menghitung dzikir dengan satu tombol.

## Masalah
Menghitung dzikir dengan jari sering membuat hitungan terlewat.

## Fitur (rencana)
- Tombol +1 dan Reset
- Pilihan target (33, 99, atau bebas)
- Hitungan tersimpan walau halaman di-refresh

## Pembuat
Zawil Kiram, TRO 26, Sekolah Vokasi Undip
