[CONTEXT] Saya mahasiswa baru yang masih memperdalam dasar pemrograman,

[OBJECTIVE] Buat aplikasi web "Penghitung Tasbih" yang sederhana dan bisa
dipublikasikan ke Vercel atau GitHub Pages.

[TECH] HTML, CSS, JavaScript vanilla (tanpa framework dan tanpa backend).
Data disimpan di localStorage.

[FEATURES]
1. Angka hitungan besar di layar
2. Tombol besar +1 untuk menambah hitungan
3. Tombol Reset
4. Pilihan target (33, 99, atau angka bebas)
5. Saat hitungan mencapai target, tampilkan pesan dan getarkan HP (opsional)
6. Hitungan tetap tersimpan setelah halaman di-refresh
7. Validasi: target harus angka lebih dari 0

[UI/UX] Modern, bersih, tombol besar dan nyaman ditap di HP (responsive).
